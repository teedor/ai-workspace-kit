---
name: idea
description: Capture an idea properly, with the honest case against it and a test that would settle it, before it gets anywhere near finished work. Use when I say "I've had an idea", "what if we…", or "write this idea up".
---

Write up the idea I've just described as the next numbered file in `ideas/`
(`001-short-name.md`, `002-…`).

Be a real sceptic, not an enthusiast. Include:

- **The idea:** one sentence
- **Where it came from:** me, Claude, a colleague, something I read
- **The case for**
- **The case against:** honestly, as strongly as you'd argue it if you disagreed
- **How we'd find out:** the specific test or evidence that would settle it. If no test
  is possible, say "this is an opinion" plainly.
- **Status:** `open`

Then tell me in two lines what you really think, and add the test to
`notes/open-questions.md` so we actually run it. When an idea is tested, update
its status and what happened. **Ideas that didn't work are kept, never deleted.**
