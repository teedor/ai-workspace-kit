# Literature

- `sources.md`: the register of everything I might cite. Only I fill in "Read".
- `notes/<key>.md`: one note per paper (made by `/sources`).
- `references.bib`: built from DOIs or a Zotero export, never from memory.
- `pdfs/`: the papers themselves. Kept out of git to save space, so keep them
  in Zotero (or another backed-up place) too.
