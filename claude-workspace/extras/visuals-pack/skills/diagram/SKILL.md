Draw the diagram I describe. It's free: no key, no account, no paid service.

1. **Ask only what you must:** what it shows and who it's for. Keep it to
   what fits on one screen; split a big one into two.
2. **Pick the format:**
   - **Mermaid** for flowcharts, timelines, sequences, family trees and org
     charts: write it in a Markdown file inside a ```` ```mermaid ```` block.
   - **SVG** for anything Mermaid draws badly (a simple map, a labelled
     layout): write the SVG by hand, plain shapes and readable text.
   Save it in `drafts/` with a plain name, and add it to `review-queue.md`
   like any other draft.
3. **Show me.** Make a small HTML preview next to it (for Mermaid, one page
   that loads Mermaid from cdn.jsdelivr.net and renders the block) and open
   it in the Code tab's browser pane, or tell me how to open it. If I want
   an image file to paste elsewhere, tell me about mermaid.live (**Actions →
   PNG or SVG**) and that it's a website: nothing confidential.
4. **Facts in diagrams follow rule 2.** Names, dates and relationships come
   from my notes or sources, never from memory. Anything uncertain is marked
   with a "?" and goes in `notes/open-questions.md`.
5. Change it by editing the same file; git keeps the history.
