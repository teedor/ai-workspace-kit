# Ideas

Thoughts that aren't proven yet. They live here so they don't sneak into
finished work before they've been tested.

Each idea gets one file (`001-short-name.md`, made with `/idea`) holding:
- **The idea:** in a sentence
- **The case for**
- **The case against:** honestly
- **How we'd find out:** the specific test that settles it
- **Status:** `open` · `testing` · `worked` · `didn't work` · `parked`

Ideas that didn't work are **kept**, with the reason. Six months later, "did we
ever try X?" has an answer.
