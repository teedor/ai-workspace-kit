# inbox: put new things here

**This is the one folder you need to remember.** Drop anything in here and tell
Claude: notes typed on your phone, a photo of a whiteboard, a PDF, a saved
email, a document, a screenshot, an error message, a voice-note transcript.
No naming, no sorting. That's Claude's job.

Then type `/intake` (or say "process the inbox").

Claude reads everything, files it where it belongs, notes what it learned,
moves the originals to `private/archive/` so nothing is ever lost, and tells
you what it did.

**An empty inbox (just this README) means everything has been dealt with.**
Anything Claude couldn't handle stays here, and it tells you why.

⚠️ No passwords, keys, or other people's personal details. If something like
that lands here by mistake, Claude will tell you rather than file it.
