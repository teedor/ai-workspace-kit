# Glossary

Terms that come up, in plain English. Used by `/plain` when explaining things.

| Term | What it means |
|---|---|
| Git | A tool that saves snapshots of this folder so you can see what changed and go back. |
| Commit | One saved snapshot, with a note saying what changed. |
| Repository | A folder whose history git is keeping. |
| Skill | A saved set of instructions you can run by typing `/` and its name. |
| CLAUDE.md | The file Claude reads at the start of every session; its standing orders. |
